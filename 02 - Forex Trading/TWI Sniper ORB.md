## What it does
Opening Range Breakout, matching what Adam calls the "JP/Pat sniper playbook":
1. **M15 first candle of the session** = Opening Range (ORH/ORL = candle high/low).
2. Trade only **with** the higher-timeframe trend (H1 EMA filter — on for gold by default, off for forex by default, see profile table below).
3. **M5 candle closes beyond the range** → sets direction (long/short), doesn't enter yet.
4. **Does not chase.** Waits for a retrace into a Point of Interest — demand/supply zone (prior FVG), the fresh impulse FVG from the break, or the range midline.
5. Prefers a **sweep of the zone then close back** ("sniper wick") over a plain touch — same accept/reject-at-a-key-level logic as [[TWI True North]]'s POC decision, independently arrived at in MQL5.
6. Stop beyond the zone; optional partial close at target R, move to break-even, trail the remainder.

Two alternate entry modes exist besides the sniper retrace: aggressive break-and-close, and sweep-of-OR-extreme-then-close-back.

## Asset profile system (new in v2.60/2.61) — this is the whole forex/gold story
Adam ran this on gold ("works amazing") and separately on forex pairs, where it underperformed. The file has one `ENUM_ASSET_PROFILE` switch (`Auto` / `Gold` / `Forex` / `Manual`) that resolves **every distance input from pips, not raw broker points**, into two fully separate blocks — so the exact same EA logic runs on both asset classes without the numbers fighting each other:

| Setting (pips) | Gold | Forex | Why they need to differ |
|---|---|---|---|
| Min opening range | 80 | 4 | Gold's ATR is naturally huge vs. a major pair's |
| Max opening range | 8000 | 200 | Same reason, ceiling side |
| SL buffer | 80 | 5 | Zone buffer scaled to typical volatility |
| BE offset | 20 | 2 | |
| Trail | 80 | 8 | |
| **Max spread** | **350** | **15 (was 4)** | **see fix below** |
| Slippage/deviation | 30 | 3 | |
| Breaks allowed/session | 1 | 4 | Forex re-arms more; gold trends harder off one break |
| Max trades/session | 2 | 3 | |
| Max trades/day | 2 | 6 | |
| HTF trend filter | ON | OFF | Forex majors chop more inside a session; gold trends |
| Re-arm requires close back inside range | ON | OFF | |

`PointsPerPip()` converts pips→points using the symbol's digit count (3 or 5 digits = 10 points/pip, else 1), and `SymbolLooksLikeMetal()` auto-detects gold/silver by symbol name (XAU/GOLD/XAG/SILVER) when `InpAssetProfile = Auto` (the default). Everything downstream reads the resolved `g_*` point values, never the raw pip inputs directly.

## The forex fix (2026-08-20, Jarvis)
Scanned the profile table above for anything disproportionate between the two asset blocks, since "gold works, forex doesn't" with the same underlying logic pointed at a filter that's silently too tight on one side. Found it: **`InpFxMaxSpread` was 4 pips.** Gold's own cap (350 raw points) is proportionally far looser. A live spread anywhere near or above 4 pips on a forex pair — completely normal outside peak London/NY overlap liquidity — means `SpreadOK()` silently blocks *every* entry, with zero error or log noise. It just looks like the EA does nothing. That symptom matches exactly what Adam described.

**Fix applied: raised `InpFxMaxSpread` from 4 → 15 pips.** Still tight enough to reject genuinely bad-liquidity conditions, loose enough that a typical 1–3 pip major-pair spread (or a wider one on a minor/exotic) doesn't get killed by default. It's an input — Adam can tune it per broker/pair from the EA's own settings panel, no recompile needed.

Everything else in the forex block (min/max range, SL buffer, trail, break/trade caps, HTF filter off) was already sanely scaled versus gold's — no other proportional outlier found on this pass.

**If forex is still quiet after this**, the file's own dashboard answers why instead of Jarvis having to guess again — see Diagnostics below. Read the "Status:" line on the on-chart panel; it names the exact blocker live (range too small, spread over cap, trend filter, session/day cap, waiting to re-arm, etc.) via `BlockingReason()`.

## Diagnostics & dashboard (new in v2.60/2.61)
Grok's build added real visibility that v2.10 didn't have:
- **Live blocking reason** (`BlockingReason()`) — one line, always answers "why isn't this trading right now."
- **Per-session counters** (`dgRangeSmall/dgRangeBig/dgSpread/dgHTF/dgNoBreak/dgBreaks/dgCapSess/dgCapDay/dgRearm/dgTrades`) printed to the log on every session close (`ReportSession()`) — turns "nothing happened" into "4 bars saw no break, spread blocked 12 bars, 1 trade fired."
- **Order-failure visibility** (`g_failCount`/`g_lastFail`/`g_lastRetcode`) — a rejected broker order used to vanish silently; now it's on the dashboard.
- **On-chart dashboard** (`OBJ_LABEL` panel, replaces the old `Comment()`-only panel, though the legacy panel still exists via `InpShowPanel` for anyone who prefers it) shows profile, session, range, direction/armed state, trade counts, day P/L, live spread vs. cap, and the rejection counters.
- **Original-risk position tracking** (`PosTrack` struct / `g_track[]`) — R-multiple math for break-even/partial/trail is computed against the position's *original* stop distance, immune to the stop having already been moved to break-even. v2.10 didn't have this and would have mis-measured R after the first BE move.
- **Re-arm logic** (`CheckRearm`) — allows multiple breaks per session (gold: 1, forex: 4 by default) with an optional "must close back inside the range first" gate, so a failed break can re-fire instead of the session going dead after one false start.
- **Auto chart-timeframe switching** (`InpAutoSetChartTF`) and **history preloading** (`WarmSeries`/`PreloadAllSeries`) — quality-of-life additions, chart still isn't read for trading decisions (every series is pulled explicitly).
- **Per-session historical range drawing with auto-trim** (`TrimOldRanges`, `InpKeepRangeCount`) — past sessions' ranges stay visible on the chart instead of being overwritten, capped so the chart doesn't fill up.

## Risk parameters tightened 2026-08-24 — root-caused, not guessed
Diagnosed the actual mechanism before touching anything: `InpBETriggerR` gates break-even on reaching the *full original risk* (1R) in profit — if the trade reverses before hitting that threshold, zero protection has activated, and a $10+ profit can round-trip straight to the original stop loss. That's the real cause of the "up then negative" pattern Adam described, not the trail distance.

**Two changes made, confirmed with Adam before touching the live file:**
- `InpBETriggerR`: **1.0 → 0.5** — break-even-plus now triggers at half the original risk instead of the full risk, protecting gains much sooner.
- `InpGoldTrail`: **80 → 10** — once protected, the stop now follows price tightly (10 points) instead of giving back a wide 80-point cushion.

// How many raw points make one pip on this symbol.
// 5-digit forex and 3-digit gold/JPY quote a tenth of a pip per point.
double PointsPerPip()
  {
   int d = DigitsUsed();
   if(d == 3 || d == 5)
      return 10.0;
   return 1.0;
  }

bool SymbolLooksLikeMetal()
  {
   string s = _Symbol;
   StringToUpper(s);
   if(StringFind(s, "XAU")  >= 0)
      return true;
   if(StringFind(s, "GOLD") >= 0)
      return true;
   if(StringFind(s, "XAG")  >= 0)
      return true;
   if(StringFind(s, "SILVER") >= 0)
      return true;
   return false;
  }

ENUM_ASSET_PROFILE EffectiveProfile()
  {
   if(InpAssetProfile != PROFILE_AUTO)
      return InpAssetProfile;
   return (SymbolLooksLikeMetal() ? PROFILE_GOLD : PROFILE_FOREX);
  }

void ResolveProfile()
  {
   ENUM_ASSET_PROFILE p   = EffectiveProfile();
   double             ppp = PointsPerPip();

   if(p == PROFILE_GOLD)
     {
      g_profileName = "GOLD";
      g_minRange  = InpGoldMinRange  * ppp;
      g_maxRange  = InpGoldMaxRange  * ppp;
      g_minBreak  = InpGoldMinBreak  * ppp;
      g_minFvg    = InpGoldMinFVG    * ppp;
      g_slBuffer  = InpGoldSLBuffer  * ppp;
      g_beOffset  = InpGoldBEOffset  * ppp;
      g_trail     = InpGoldTrail     * ppp;
      g_fixedTp   = InpGoldFixedTP   * ppp;
      g_maxSpread = InpGoldMaxSpread * ppp;
      g_slippage  = InpGoldSlippage  * ppp;
      g_maxBreaks  = InpGoldMaxBreaks;
      g_maxTrdSess = InpGoldMaxTrdSession;
      g_maxTrdDay  = InpGoldMaxTrdDay;
      g_htfFilter   = InpGoldHTFFilter;
      g_rearmInside = InpGoldRearmInside;
     }
   else
      if(p == PROFILE_FOREX)
        {
         g_profileName = "FOREX";
         g_minRange  = InpFxMinRange  * ppp;
         g_maxRange  = InpFxMaxRange  * ppp;
         g_minBreak  = InpFxMinBreak  * ppp;
         g_minFvg    = InpFxMinFVG    * ppp;
         g_slBuffer  = InpFxSLBuffer  * ppp;
         g_beOffset  = InpFxBEOffset  * ppp;
         g_trail     = InpFxTrail     * ppp;
         g_fixedTp   = InpFxFixedTP   * ppp;
         g_maxSpread = InpFxMaxSpread * ppp;
         g_slippage  = InpFxSlippage  * ppp;
         g_maxBreaks  = InpFxMaxBreaks;
         g_maxTrdSess = InpFxMaxTrdSession;
         g_maxTrdDay  = InpFxMaxTrdDay;
         g_htfFilter   = InpFxHTFFilter;
         g_rearmInside = InpFxRearmInside;
        }
      else
        {
         g_profileName = "MANUAL";
         g_minRange  = (double)InpMinRangePoints;
         g_maxRange  = (double)InpMaxRangePoints;
         g_minBreak  = (double)InpMinBreakPoints;
         g_minFvg    = (double)InpMinFVGPoints;
         g_slBuffer  = (double)InpSLBufferPoints;
         g_beOffset  = (double)InpBEOffsetPoints;
         g_trail     = (double)InpTrailPoints;
         g_fixedTp   = (double)InpFixedTPPoints;
         g_maxSpread = (double)InpMaxSpreadPoints;
         g_slippage  = (double)InpSlippagePoints;
         g_maxBreaks  = InpMaxBreaksPerSess;
         g_maxTrdSess = InpMaxTradesSession;
         g_maxTrdDay  = InpMaxTradesDay;
         g_htfFilter   = InpHTFTrendFilter;
         g_rearmInside = InpRearmInsideRange;
        }

   if(g_slippage < 1.0)
      g_slippage = 1.0;
   if(g_maxBreaks < 1)
      g_maxBreaks = 1;
  }

void PrintProfile()
  {
   double ppp = PointsPerPip();
   Print("TWI Sniper | profile ", g_profileName,
         (InpAssetProfile == PROFILE_AUTO ? " (auto-detected)" : " (forced)"),
         "   digits=", IntegerToString(DigitsUsed()),
         "   1 pip = ", DoubleToString(ppp, 0), " points = ",
         DoubleToString(ppp * Pt(), DigitsUsed()), " price");
   Print("TWI Sniper | resolved points -> minRange ", DoubleToString(g_minRange, 0),
         "  maxRange ", DoubleToString(g_maxRange, 0),
         "  slBuffer ", DoubleToString(g_slBuffer, 0),
         "  beOffset ", DoubleToString(g_beOffset, 0),
         "  trail ",    DoubleToString(g_trail, 0),
         "  minFVG ",   DoubleToString(g_minFvg, 0),
         "  maxSpread ", DoubleToString(g_maxSpread, 0));
   if(SpreadPoints() > g_maxSpread)
      Print("TWI Sniper | WARNING current spread ", DoubleToString(SpreadPoints(), 0),
            " points exceeds the profile limit ", DoubleToString(g_maxSpread, 0),
            " - no trades will be taken until it tightens.");
  }

double StopsMinDistance()
  {
   int lvl = (int)SymbolInfoInteger(_Symbol, SYMBOL_TRADE_STOPS_LEVEL);
   int frz = (int)SymbolInfoInteger(_Symbol, SYMBOL_TRADE_FREEZE_LEVEL);
   int use = (lvl > frz) ? lvl : frz;
   return (double)use * Pt();
  }

datetime TimeFromHMS(int h, int m, datetime refDay)
  {
   MqlDateTime dt;
   TimeToStruct(refDay, dt);
   dt.hour = h;
   dt.min  = m;
   dt.sec  = 0;
   return StructToTime(dt);
  }

bool IsFridayCloseWindow()
  {
   if(InpFridayCloseMin <= 0)
      return false;
   MqlDateTime dt;
   TimeToStruct(TimeCurrent(), dt);
   if(dt.day_of_week != 5)
      return false;
   datetime closeAt = TimeFromHMS(23, 55, TimeCurrent());
   return (TimeCurrent() >= closeAt - InpFridayCloseMin * 60);
  }

void DetectFilling()
  {
   long filling = SymbolInfoInteger(_Symbol, SYMBOL_FILLING_MODE);
   if((filling & SYMBOL_FILLING_FOK) != 0)
      trade.SetTypeFilling(ORDER_FILLING_FOK);
   else
      if((filling & SYMBOL_FILLING_IOC) != 0)
         trade.SetTypeFilling(ORDER_FILLING_IOC);
      else
         trade.SetTypeFilling(ORDER_FILLING_RETURN);
  }

double ClampLots(double lots)
  {
   double minl = SymbolInfoDouble(_Symbol, SYMBOL_VOLUME_MIN);
   double maxl = SymbolInfoDouble(_Symbol, SYMBOL_VOLUME_MAX);
   double step = SymbolInfoDouble(_Symbol, SYMBOL_VOLUME_STEP);
   if(step <= 0.0)
      step = 0.01;
   lots = MathFloor(lots / step + 1e-8) * step;
   if(lots < minl)
      lots = minl;
   if(lots > maxl)
      lots = maxl;

   int volDigits = 2;
   if(step >= 1.0)
      volDigits = 0;
   else
      if(step >= 0.1)
         volDigits = 1;
      else
         if(step >= 0.01)
            volDigits = 2;
         else
            volDigits = 3;

   return NormalizeDouble(lots, volDigits);
  }

double LotsForRisk(double slDistance)
  {
   if(InpLotMode == LOT_FIXED || slDistance <= 0.0)
      return ClampLots(InpFixedLots);

   double tickVal  = SymbolInfoDouble(_Symbol, SYMBOL_TRADE_TICK_VALUE);
   double tickSize = SymbolInfoDouble(_Symbol, SYMBOL_TRADE_TICK_SIZE);
   if(tickVal <= 0.0 || tickSize <= 0.0)
      return ClampLots(InpFixedLots);

   double riskMoney   = acct.Balance() * (InpRiskPercent / 100.0);
   double moneyPerLot = (slDistance / tickSize) * tickVal;
   if(moneyPerLot <= 0.0)
      return ClampLots(InpFixedLots);

   return ClampLots(riskMoney / moneyPerLot);
  }

     }
  }

// POSITION TRACKING (original risk + partial-close flag, in memory)
//====================================================================
int TrackFind(ulong ticket)
  {
   for(int i = 0; i < ArraySize(g_track); i++)
      if(g_track[i].ticket == ticket)
         return i;
   return -1;
  }

int TrackAdopt(ulong ticket, double entry, double sl, long ptype)
  {
   int n = ArraySize(g_track);
   ArrayResize(g_track, n + 1);
   g_track[n].ticket = ticket;
   g_track[n].entry  = entry;
   g_track[n].risk   = (sl > 0.0) ? MathAbs(entry - sl) : 0.0;

   // If the stop is already at or beyond entry the position has been managed
   // before (EA restart mid-trade) - never re-fire the partial close.
   bool alreadyManaged = false;
   if(sl > 0.0)
     {
      if(ptype == POSITION_TYPE_BUY  && sl >= entry)
         alreadyManaged = true;
      if(ptype == POSITION_TYPE_SELL && sl <= entry)
         alreadyManaged = true;
     }
   g_track[n].partialDone = alreadyManaged;
   return n;
  }

void TrackPrune()
  {
   int n = ArraySize(g_track);
   for(int i = n - 1; i >= 0; i--)
     {
      if(PositionSelectByTicket(g_track[i].ticket))
         continue;
      for(int j = i; j < ArraySize(g_track) - 1; j++)
         g_track[j] = g_track[j + 1];
      ArrayResize(g_track, ArraySize(g_track) - 1);
     }
  }

// DAY / SESSION STATISTICS  (derived from real deal history)
//====================================================================
void RefreshStats(bool force)
  {
   datetime now = TimeCurrent();
   if(!force && now - lastStatsTime < 5)
      return;
   lastStatsTime = now;

   MqlDateTime dt;
   TimeToStruct(now, dt);
   dt.hour = 0;
   dt.min  = 0;
   dt.sec  = 0;
   datetime dayStart = StructToTime(dt);
   dayStamp = dayStart;

   datetime scanFrom = dayStart;
   if(sess.start > 0 && sess.start < scanFrom)
      scanFrom = sess.start;

   dayTrades  = 0;
   sessTrades = 0;
   dayPnL     = 0.0;

   if(!HistorySelect(scanFrom, now + 60))
      return;

   int total = HistoryDealsTotal();
   for(int i = 0; i < total; i++)
     {
      ulong ticket = HistoryDealGetTicket(i);
      if(ticket == 0)
         continue;
      if(HistoryDealGetString(ticket, DEAL_SYMBOL) != _Symbol)
         continue;
      if((long)HistoryDealGetInteger(ticket, DEAL_MAGIC) != InpMagic)
         continue;

      long     entry = HistoryDealGetInteger(ticket, DEAL_ENTRY);
      datetime dtime = (datetime)HistoryDealGetInteger(ticket, DEAL_TIME);

      if(entry == DEAL_ENTRY_IN)
        {
         if(dtime >= dayStart)
            dayTrades++;
         if(sess.start > 0 && dtime >= sess.start)
            sessTrades++;
        }
      else
         if(entry == DEAL_ENTRY_OUT || entry == DEAL_ENTRY_INOUT || entry == DEAL_ENTRY_OUT_BY)
           {
            if(dtime >= dayStart)
               dayPnL += HistoryDealGetDouble(ticket, DEAL_PROFIT)
                         + HistoryDealGetDouble(ticket, DEAL_SWAP)
                         + HistoryDealGetDouble(ticket, DEAL_COMMISSION);
           }
     }
  }

bool DailyLimitsHit()
  {
   if(InpMaxDailyLoss > 0.0 && dayPnL <= -MathAbs(InpMaxDailyLoss))
      return true;
   if(InpMaxDailyProfit > 0.0 && dayPnL >= InpMaxDailyProfit)
      return true;
   if(g_maxTrdDay > 0 && dayTrades >= g_maxTrdDay)
      return true;
   return false;
  }

bool SessionLimitHit()
  {
   return (g_maxTrdSess > 0 && sessTrades >= g_maxTrdSess);
  }

      return 0.0;

int HTFBias()
  {
   if(!g_htfFilter)
      return 0;
   double ema = EMAValue();
   if(ema <= 0.0)
      return 0;
   double bid = SymbolInfoDouble(_Symbol, SYMBOL_BID);
   if(bid > ema)
      return 1;
   if(bid < ema)
      return -1;
   return 0;
  }

   if(dir > 0 && InpDirection == DIR_SHORT_ONLY)
      return false;
   if(dir < 0 && InpDirection == DIR_LONG_ONLY)
      return false;
   int bias = HTFBias();
   if(bias != 0 && bias != dir)
      return false;
   return true;
  }

// Handles windows that cross midnight by also testing yesterday's anchor.
bool WindowFor(int sh, int sm, int eh, int em, datetime now, datetime &st, datetime &en)
  {
   for(int back = 0; back <= 1; back++)
     {
      datetime refDay = now - (datetime)(back * 24 * 3600);
      datetime s = TimeFromHMS(sh, sm, refDay);
      datetime e = TimeFromHMS(eh, em, refDay);
      if(e <= s)
         e += 24 * 3600;
      if(now >= s && now < e)
        {
         st = s;
         en = e;
         return true;
        }
     }
   return false;
  }

void PickActiveWindow(datetime now, datetime &st, datetime &en)
  {
   st = 0;
   en = 0;

   if(InpUseAsia && SessionSelected(SESSION_ASIA))
      if(WindowFor(InpAsiaStartHour, InpAsiaStartMinute, InpAsiaEndHour, InpAsiaEndMinute, now, st, en))
         return;

   if(InpUseLondon && SessionSelected(SESSION_LONDON))
      if(WindowFor(InpLondonStartHour, InpLondonStartMinute, InpLondonEndHour, InpLondonEndMinute, now, st, en))
         return;

   if(InpUseNewYork && SessionSelected(SESSION_NEWYORK))
      if(WindowFor(InpNYStartHour, InpNYStartMinute, InpNYEndHour, InpNYEndMinute, now, st, en))
         return;

   st = 0;
   en = 0;
  }

// OPENING RANGE

bool BuildOpeningRange()
  {
   if(sess.orSkipped)
      return false;

   int period = PeriodSeconds(InpRangeTF);
   if(period <= 0)
      return false;

   datetime barOpen = sess.start - (datetime)(sess.start % period);
   if(barOpen < sess.start)
      barOpen += period;

   if(TimeCurrent() < barOpen + period)
      return false;   // range candle has not closed yet

   MqlRates r[];
   ArraySetAsSeries(r, true);
   int n = CopyRates(_Symbol, InpRangeTF, 0, 60, r);
   if(n < 2)
      return false;

   int idx = -1;
   for(int i = 1; i < n; i++)          // index 0 is the forming bar
     {
      if(r[i].time == barOpen)
        {
         idx = i;
         break;
        }
     }

   if(idx < 0)
     {
      for(int j = n - 1; j >= 1; j--)
        {
         if(r[j].time >= sess.start && r[j].time < sess.start + period * 2)
           {
            idx = j;
            break;
           }
        }
     }

   if(idx < 0)
      return false;

   double orh = r[idx].high;
   double orl = r[idx].low;
   if(orh <= orl)
      return false;

   double height = (orh - orl) / Pt();
   if(height < g_minRange || height > g_maxRange)
     {
      sess.orSkipped = true;
      if(height < g_minRange)
         dgRangeSmall++;
      else
         dgRangeBig++;
      Log("Opening range skipped - height " + DoubleToString(height, 0)
          + " points (allowed " + DoubleToString(g_minRange, 0)
          + " to " + DoubleToString(g_maxRange, 0) + ")");
      return false;
     }

   sess.orh       = orh;
   sess.orl       = orl;
   sess.orBarTime = r[idx].time;
   sess.mid       = (orh + orl) * 0.5;
   sess.orReady   = true;

   Log("Opening range  ORH " + DoubleToString(orh, DigitsUsed())
       + "  ORL " + DoubleToString(orl, DigitsUsed())
       + "  bar " + TimeToString(sess.orBarTime, TIME_DATE | TIME_MINUTES));
   return true;
  }

//====================================================================
bool CopySignal(MqlRates &rates[], int count)
  {
   ArraySetAsSeries(rates, true);
   int n = CopyRates(_Symbol, InpSignalTF, 0, count, rates);
   return (n >= 5);
  }

void ScanPOI(int dir)
  {
   MqlRates r[];
   int look = (InpFVGLookback > 10) ? InpFVGLookback : 10;
   if(!CopySignal(r, look + 5))
      return;

   sess.hasFvg    = false;
   sess.hasDemand = false;

   datetime newestImpulse = 0;
   datetime newestDemand  = 0;
   int      impulseWindow = PeriodSeconds(InpSignalTF) * 8;

   for(int i = 1; i <= look - 2 && i + 2 < ArraySize(r); i++)
     {
      double gapLo = 0.0;
      double gapHi = 0.0;

      if(dir > 0)
        {
         gapLo = r[i + 2].high;
         gapHi = r[i].low;
        }
      else
        {
         gapLo = r[i].high;
         gapHi = r[i + 2].low;
        }

      if(gapHi <= gapLo)
         continue;
      if((gapHi - gapLo) / Pt() < g_minFvg)
         continue;

      // Impulse FVG: created around the break candle
      if(r[i].time >= sess.breakTime - impulseWindow)
        {
         if(!sess.hasFvg || r[i].time > newestImpulse)
           {
            sess.fvgLo    = gapLo;
            sess.fvgHi    = gapHi;
            sess.hasFvg   = true;
            newestImpulse = r[i].time;
           }
        }

      // Demand (long) sits at or below the midline; supply (short) at or above
      bool inZoneHalf = (dir > 0) ? (gapHi <= sess.mid + 2.0 * Pt())
                                  : (gapLo >= sess.mid - 2.0 * Pt());
      if(inZoneHalf && r[i].time <= sess.breakTime)
        {
         if(!sess.hasDemand || r[i].time > newestDemand)
           {
            sess.demandLo  = gapLo;
            sess.demandHi  = gapHi;
            sess.hasDemand = true;
            newestDemand   = r[i].time;
           }
        }
     }

   // Fallback 1: base of the impulse (last opposite candle before the break)
   if(!sess.hasDemand)
     {
      for(int j = 1; j <= look - 1 && j < ArraySize(r); j++)
        {
         if(r[j].time > sess.breakTime)
            continue;
         if(dir > 0 && r[j].close < r[j].open)
           {
            sess.demandLo  = r[j].low;
            sess.demandHi  = MathMax(r[j].open, r[j].close);
            sess.hasDemand = true;
            break;
           }
         if(dir < 0 && r[j].close > r[j].open)
           {
            sess.demandHi  = r[j].high;
            sess.demandLo  = MathMin(r[j].open, r[j].close);
            sess.hasDemand = true;
            break;
           }
        }
     }

   // Fallback 2: discount / premium half of the opening range
   if(!sess.hasDemand)
     {
      if(dir > 0)
        {
         sess.demandLo = sess.orl;
         sess.demandHi = sess.mid;
        }
      else
        {
         sess.demandHi = sess.orh;
         sess.demandLo = sess.mid;
        }
      sess.hasDemand = true;
     }
  }

void GetPOI(int dir, double &zLo, double &zHi)
  {
   zLo = 0.0;
   zHi = 0.0;

   if(InpPOI == POI_IMPULSE_FVG && sess.hasFvg)
     {
      zLo = sess.fvgLo;
      zHi = sess.fvgHi;
      return;
     }

   if(InpPOI == POI_MIDLINE)
     {
      double half = (sess.orh - sess.orl) * 0.08;
      zLo = sess.mid - half;
      zHi = sess.mid + half;
      return;
     }

   if(InpPOI == POI_ANY && sess.hasFvg)
     {
      zLo = sess.fvgLo;
      zHi = sess.fvgHi;
      return;
     }

   zLo = sess.demandLo;
   zHi = sess.demandHi;
  }

double LimitPrice(int dir, double zLo, double zHi)
  {
   double pct = (double)InpZoneFillPercent;
   if(pct < 0.0)
      pct = 0.0;
   if(pct > 100.0)
      pct = 100.0;
   pct /= 100.0;

   if(dir > 0)
      return NormalizePrice(zLo + (zHi - zLo) * pct);
   return NormalizePrice(zHi - (zHi - zLo) * pct);
  }

double StopPrice(int dir, double zLo, double zHi)
  {
   double buf = g_slBuffer * Pt();
   if(dir > 0)
      return NormalizePrice(zLo - buf);
   return NormalizePrice(zHi + buf);
  }

double TakePrice(int dir, double entry, double sl)
  {
   if(InpTPMode == TP_RANGE)
     {
      double range = sess.orh - sess.orl;
      if(dir > 0)
         return NormalizePrice(entry + range * InpRangeTPMultiple);
      return NormalizePrice(entry - range * InpRangeTPMultiple);
     }

   if(InpTPMode == TP_FIXED_POINTS)
     {
      if(dir > 0)
         return NormalizePrice(entry + g_fixedTp * Pt());
      return NormalizePrice(entry - g_fixedTp * Pt());
     }

   double risk = MathAbs(entry - sl);
   if(dir > 0)
      return NormalizePrice(entry + risk * InpRR);
   return NormalizePrice(entry - risk * InpRR);
  }

void EnforceStopsLevel(int dir, double entry, double &sl, double &tp)
  {
   double minDist = StopsMinDistance();
   if(minDist <= 0.0)
      return;

   if(dir > 0)
     {
      if(entry - sl < minDist)
         sl = NormalizePrice(entry - minDist);
      if(tp - entry < minDist)
         tp = NormalizePrice(entry + minDist);
     }
   else
     {
      if(sl - entry < minDist)
         sl = NormalizePrice(entry + minDist);
      if(entry - tp < minDist)
         tp = NormalizePrice(entry - minDist);
     }
  }

// Keep only the most recent N session ranges so the chart cannot fill up.
void TrimOldRanges()
  {
   if(!InpKeepPastRanges)
      return;

   string stamps[];
   ArrayResize(stamps, 0);

   int total = ObjectsTotal(0, 0, -1);
   for(int i = 0; i < total; i++)
     {
      string name = ObjectName(0, i, 0, -1);
      if(StringFind(name, prefix + "OR") != 0)
         continue;
      // NOTE: prefix itself contains underscores ("TWI_SNIPER_"), so the search
      // must start past it or StringFind returns the wrong separator.
      int head = StringLen(prefix) + 2;          // skip prefix + "OR"
      int us   = StringFind(name, "_", head);
      if(us <= head)
         continue;
      string stamp = StringSubstr(name, head, us - head);
      bool seen = false;
      for(int k = 0; k < ArraySize(stamps); k++)
         if(stamps[k] == stamp)
           {
            seen = true;
            break;
           }
      if(!seen)
        {
         int n = ArraySize(stamps);
         ArrayResize(stamps, n + 1);
         stamps[n] = stamp;
        }
     }

   int keep = MathMax(InpKeepRangeCount, 1);
   if(ArraySize(stamps) <= keep)
      return;

   // ArraySort() does not accept string arrays in MQL5 - sort by hand.
   // All stamps are fixed-width numeric text, so a plain compare orders them.
   for(int a = 0; a < ArraySize(stamps) - 1; a++)
      for(int b = 0; b < ArraySize(stamps) - 1 - a; b++)
         if(StringCompare(stamps[b], stamps[b + 1]) > 0)
           {
            string tmp   = stamps[b];
            stamps[b]    = stamps[b + 1];
            stamps[b + 1] = tmp;
           }

   int drop = ArraySize(stamps) - keep;
   for(int d = 0; d < drop; d++)
     {
      string dead = prefix + "OR" + stamps[d] + "_";
      for(int j = ObjectsTotal(0, 0, -1) - 1; j >= 0; j--)
        {
         string nm = ObjectName(0, j, 0, -1);
         if(StringFind(nm, dead) == 0)
            ObjectDelete(0, nm);
        }
     }
  }

void DrawSetup()
  {
   if(!InpDrawObjects || !sess.orReady || sess.start == 0)

   string   tag = RangeTag();
   datetime t1  = sess.orBarTime;

   DrawRect(tag + "DISC", t1, sess.mid, t2, sess.orl, InpBullColor);

   DrawSeg(tag + "ORH", t1, sess.orh, t2, sess.orh, InpORColor, STYLE_SOLID, 2);
   DrawSeg(tag + "ORL", t1, sess.orl, t2, sess.orl, InpORColor, STYLE_SOLID, 2);
   DrawSeg(tag + "MID", t1, sess.mid, t2, sess.mid, clrDimGray, STYLE_DOT,   1);

   DrawTag(tag + "L_H", t1, sess.orh, " " + SessionName() + " ORH " + DoubleToString(sess.orh, DigitsUsed()) + sz, InpORColor);
   DrawTag(tag + "L_L", t1, sess.orl, " " + SessionName() + " ORL " + DoubleToString(sess.orl, DigitsUsed()), InpORColor);

     {

      DrawRect(tag + "ZONE", t1, sess.demandHi, t2, sess.demandLo, zc);
      DrawTag(tag + "L_Z", t1, sess.demandHi, " Zone", zc);
     }

   if(sess.hasFvg)
      DrawRect(tag + "FVG", t1, sess.fvgHi, t2, sess.fvgLo, clrGoldenrod);

   TrimOldRanges();
  }

string SessionName()
  {
   if(sess.start == 0)
      return "none";
   MqlDateTime dt;
   TimeToStruct(sess.start, dt);
   if(dt.hour == InpAsiaStartHour   && dt.min == InpAsiaStartMinute)
      return "Asia";
   if(dt.hour == InpLondonStartHour && dt.min == InpLondonStartMinute)
      return "London";
   if(dt.hour == InpNYStartHour     && dt.min == InpNYStartMinute)
      return "New York";
   return "session";
  }

string BlockingReason()
  {
   if(sess.start == 0)
      return "no session active";
   if(!sess.orReady)
      return (sess.orSkipped ? "range rejected - out of size limits" : "waiting for range candle to close");
   if(IsFridayCloseWindow())
      return "Friday close window";
   if(DailyLimitsHit())
      return "daily cap reached";
   if(SessionLimitHit())
      return "session cap reached";
   if(!SpreadOK())
      return "spread " + DoubleToString(SpreadPoints(), 0) + " > limit " + DoubleToString(g_maxSpread, 0);
   if(CountOpen() > 0)
      return "position open - managing";
   if(!sess.armed)
      return (sess.breaks >= g_maxBreaks ? "break budget used" : "waiting to re-arm");
   return "armed - hunting a break";
  }

bool PlaceMarket(int dir, double sl)
  {
   double ask   = SymbolInfoDouble(_Symbol, SYMBOL_ASK);
   double bid   = SymbolInfoDouble(_Symbol, SYMBOL_BID);
   double entry = (dir > 0) ? ask : bid;

   double tp = TakePrice(dir, entry, sl);
   EnforceStopsLevel(dir, entry, sl, tp);

   double lots = LotsForRisk(MathAbs(entry - sl));

   bool ok = false;
   if(dir > 0)
      ok = trade.Buy(lots, _Symbol, 0.0, sl, tp, InpComment);
   else
      ok = trade.Sell(lots, _Symbol, 0.0, sl, tp, InpComment);

   if(ok)
     {
      sessTrades++;
      dayTrades++;
      dgTrades++;
      sess.setupLive = false;
      DrawMark(prefix + "ENTRY_" + IntegerToString((int)TimeCurrent()), TimeCurrent(), entry, InpSniperColor, 159);
      Log((dir > 0 ? "BUY " : "SELL ") + DoubleToString(lots, 2)
          + "  entry " + DoubleToString(entry, DigitsUsed())
          + "  sl "    + DoubleToString(sl, DigitsUsed())
          + "  tp "    + DoubleToString(tp, DigitsUsed()));
     }
   else
     {
      g_failCount++;
      g_lastRetcode = (int)trade.ResultRetcode();
      g_lastFail    = IntegerToString(g_lastRetcode) + " " + trade.ResultRetcodeDescription();
      Log("Order FAILED: " + g_lastFail + "   lots " + DoubleToString(lots, 2)
          + "  risk " + DoubleToString(MathAbs(entry - sl) / Pt(), 0) + "pt");
     }

   return ok;
  }

bool PlaceLimit(int dir, double price, double sl)
  {
   double tp = TakePrice(dir, price, sl);
   EnforceStopsLevel(dir, price, sl, tp);

   double   lots = LotsForRisk(MathAbs(price - sl));
   datetime exp  = sess.end;
   bool     ok   = false;

   if(exp > TimeCurrent() + 120)
     {
      if(dir > 0)
         ok = trade.BuyLimit(lots, price, _Symbol, sl, tp, ORDER_TIME_SPECIFIED, exp, InpComment);
      else
         ok = trade.SellLimit(lots, price, _Symbol, sl, tp, ORDER_TIME_SPECIFIED, exp, InpComment);
     }

   if(!ok)
     {
      if(dir > 0)
         ok = trade.BuyLimit(lots, price, _Symbol, sl, tp, ORDER_TIME_GTC, 0, InpComment);
      else
         ok = trade.SellLimit(lots, price, _Symbol, sl, tp, ORDER_TIME_GTC, 0, InpComment);
     }

   if(ok)
      Log("Limit parked at " + DoubleToString(price, DigitsUsed()));
   else
     {
      g_failCount++;
      g_lastRetcode = (int)trade.ResultRetcode();
      g_lastFail    = IntegerToString(g_lastRetcode) + " " + trade.ResultRetcodeDescription();
      Log("Limit FAILED: " + g_lastFail + "   lots " + DoubleToString(lots, 2));
     }

   return ok;
  }

bool CandleRejects(const MqlRates &r, int dir, double zLo, double zHi)
  {
   bool wickIn = (r.low <= zHi && r.high >= zLo);
   if(!wickIn)
      return false;
   if(dir > 0)
      return (r.close > r.open && r.close >= zLo);
   return (r.close < r.open && r.close <= zHi);
  }

bool SweptZone(const MqlRates &r, int dir, double zLo, double zHi)
  {
   if(dir > 0)
      return (r.low <= zLo && r.close > zLo);
   return (r.high >= zHi && r.close < zHi);
  }

void TrySniper(bool isNewBar)
  {
   if(sess.dir == 0 || !sess.setupLive)
      return;
   if(SessionLimitHit())
      return;
   if(CountOpen() > 0 || CountPendings() > 0)
      return;

   double zLo = 0.0, zHi = 0.0;
   GetPOI(sess.dir, zLo, zHi);
   if(zHi <= zLo)
      return;

   MqlRates r[];
   if(!CopySignal(r, 5))
      return;
   MqlRates closed = r[1];

   if(InpRequireRetrace && closed.time <= sess.breakTime)
      return;

   // Expiry is counted in BARS, so only advance it on a new signal bar.
   if(isNewBar)
     {
      sess.waitBars++;
      if(sess.waitBars > InpMaxWaitBars)
        {
         sess.setupLive = false;
         CancelPendings();
         Log("Setup expired - no sniper fill");
         return;
        }
     }

   if(InpConfirmCandle)
     {
      if(!isNewBar)
         return;
      if(!CandleRejects(closed, sess.dir, zLo, zHi))
         return;

      if(InpSweepConfirm)
        {
         bool swept = SweptZone(closed, sess.dir, zLo, zHi);
         if(!swept && ArraySize(r) > 2 && r[2].time > sess.breakTime)
            swept = SweptZone(r[2], sess.dir, zLo, zHi);
         if(!swept)
            return;
         DrawMark(prefix + "SWEEP", closed.time,
                  (sess.dir > 0 ? closed.low : closed.high), clrWhite, 159);
        }

      double sl = StopPrice(sess.dir, zLo, zHi);
      PlaceMarket(sess.dir, sl);
      return;
     }

   // No candle confirmation: rest a limit inside the zone
   double limit = LimitPrice(sess.dir, zLo, zHi);
   double slLim = StopPrice(sess.dir, zLo, zHi);
   PlaceLimit(sess.dir, limit, slLim);
  }

// After a break resolves, allow the session to hunt another one.
// Default rule: price must close back INSIDE the opening range first, which is
// the classic failed-break / re-break pattern - it prevents re-entering over
// and over on every bar of a single trend leg.
void CheckRearm(const MqlRates &closed)
  {
   if(sess.armed || !sess.orReady)
      return;
   if(sess.breaks >= g_maxBreaks)
      return;
   if(CountOpen() > 0 || CountPendings() > 0)
      return;
   if(SessionLimitHit() || DailyLimitsHit())
      return;

   if(g_rearmInside)
     {
      bool backInside = (closed.close > sess.orl && closed.close < sess.orh);
      if(!backInside)
         return;
     }

   sess.armed     = true;
   sess.breakSeen = false;
   sess.setupLive = false;
   sess.dir       = 0;
   sess.waitBars  = 0;
   dgRearm++;
   Log("Re-armed - price closed back inside the range (break "
       + IntegerToString(sess.breaks) + "/" + IntegerToString(g_maxBreaks) + " used)");
  }

void TryBreakEntry(const MqlRates &closed)
  {
   if(!sess.armed || sess.breakSeen || !sess.orReady)
      return;
   if(closed.time <= sess.orBarTime)
      return;

   int    dir      = 0;
   double minBreak = g_minBreak * Pt();

   if(InpRequireCloseBeyond)
     {
      if(closed.close > sess.orh + minBreak)
         dir = 1;
      else
         if(closed.close < sess.orl - minBreak)
            dir = -1;
     }
   else
     {
      if(closed.high > sess.orh + minBreak && closed.close > sess.orh)
         dir = 1;
      else
         if(closed.low < sess.orl - minBreak && closed.close < sess.orl)
            dir = -1;
     }

   if(dir == 0)
     {
      dgNoBreak++;
      return;
     }

   if(!DirectionAllowed(dir))
     {
      dgHTF++;
      Log("Break ignored - against the HTF trend / direction filter");
      return;
     }

   sess.dir       = dir;
   sess.breakSeen = true;
   sess.breakTime = closed.time;
   sess.waitBars  = 0;
   sess.breaks++;
   sess.armed     = false;
   dgBreaks++;
   ScanPOI(dir);
   sess.setupLive = true;

   DrawMark(prefix + "BRK", closed.time, closed.close, InpSniperColor, (dir > 0 ? 233 : 234));
   Log((dir > 0 ? "Direction LONG - M5 close above ORH " : "Direction SHORT - M5 close below ORL ")
       + DoubleToString(closed.close, DigitsUsed()));

   if(InpEntryMode == ENTRY_BREAK)
     {
      if(SessionLimitHit())
        {
         dgCapSess++;
         return;
        }
      if(CountOpen() > 0)
         return;
      double zLo = 0.0, zHi = 0.0;
      GetPOI(dir, zLo, zHi);
      double sl = StopPrice(dir, zLo, zHi);
      if(dir > 0 && sl >= closed.close)
         sl = NormalizePrice(sess.orl - g_slBuffer * Pt());
      if(dir < 0 && sl <= closed.close)
         sl = NormalizePrice(sess.orh + g_slBuffer * Pt());
      PlaceMarket(dir, sl);
      sess.setupLive = false;
     }
  }

void TrySweepEntry(const MqlRates &closed)
  {
   if(!sess.orReady || InpEntryMode != ENTRY_SWEEP)
      return;
   if(SessionLimitHit() || CountOpen() > 0)
      return;
   if(closed.time <= sess.orBarTime)
      return;

   if(closed.low < sess.orl && closed.close > sess.orl && DirectionAllowed(1))
     {
      sess.dir       = 1;
      sess.breakSeen = true;
      sess.breakTime = closed.time;
      ScanPOI(1);
      double sl = NormalizePrice(MathMin(closed.low, sess.orl) - g_slBuffer * Pt());
      PlaceMarket(1, sl);
      return;
     }

   if(closed.high > sess.orh && closed.close < sess.orh && DirectionAllowed(-1))
     {
      sess.dir       = -1;
      sess.breakSeen = true;
      sess.breakTime = closed.time;
      ScanPOI(-1);
      double sl = NormalizePrice(MathMax(closed.high, sess.orh) + g_slBuffer * Pt());
      PlaceMarket(-1, sl);
     }
  }

//====================================================================
// TRADE MANAGEMENT - break-even, partial, trail
//====================================================================
void ManageOpen()
  {
   TrackPrune();

   for(int i = PositionsTotal() - 1; i >= 0; i--)
     {
      if(!pos.SelectByIndex(i))
         continue;
      if(pos.Symbol() != _Symbol || pos.Magic() != InpMagic)
         continue;

      ulong  ticket = pos.Ticket();
      double entry  = pos.PriceOpen();
      double sl     = pos.StopLoss();
      double tp     = pos.TakeProfit();
      double volume = pos.Volume();
      long   ptype  = pos.PositionType();

      int idx = TrackFind(ticket);
      if(idx < 0)
         idx = TrackAdopt(ticket, entry, sl, ptype);

      double risk = g_track[idx].risk;      // ORIGINAL risk, not the current stop
      if(risk <= 0.0)
         continue;

      double bid = SymbolInfoDouble(_Symbol, SYMBOL_BID);
      double ask = SymbolInfoDouble(_Symbol, SYMBOL_ASK);
      double px  = (ptype == POSITION_TYPE_BUY) ? bid : ask;

      double rNow = (ptype == POSITION_TYPE_BUY) ? (px - entry) / risk
                                                 : (entry - px) / risk;

      // ---- partial close first, so the runner keeps the original sizing logic
      if(InpPartialClose && !g_track[idx].partialDone && rNow >= InpPartialAtR)
        {
         double minl     = SymbolInfoDouble(_Symbol, SYMBOL_VOLUME_MIN);
         double step     = SymbolInfoDouble(_Symbol, SYMBOL_VOLUME_STEP);
         double closeVol = ClampLots(volume * (InpPartialPercent / 100.0));

         if(closeVol >= minl && volume - closeVol >= minl - step * 0.5 && closeVol < volume)
           {
            if(trade.PositionClosePartial(ticket, closeVol))
              {
               g_track[idx].partialDone = true;
               Log("Partial close " + DoubleToString(closeVol, 2) + " at " + DoubleToString(rNow, 2) + "R");
              }
           }
         else
            g_track[idx].partialDone = true;   // cannot split - do not retry every tick
        }

      // ---- break-even
      if(InpBETriggerR > 0.0 && rNow >= InpBETriggerR)
        {
         double be = (ptype == POSITION_TYPE_BUY)
                     ? NormalizePrice(entry + g_beOffset * Pt())
                     : NormalizePrice(entry - g_beOffset * Pt());

         if(ptype == POSITION_TYPE_BUY && (sl <= 0.0 || sl < be - Pt()))
            trade.PositionModify(ticket, be, tp);
         if(ptype == POSITION_TYPE_SELL && (sl <= 0.0 || sl > be + Pt()))
            trade.PositionModify(ticket, be, tp);
        }

      // ---- trail once break-even is in place
      // Trail distance is ATR x InpATRMultiplier when InpUseATRTrail is on and
      // the ATR handle is producing real values, so a quiet market gets a tight
      // trail and a trending one gets room to run - instead of the one fixed
      // g_trail number doing both jobs. Falls back to g_trail (the original
      // fixed-points behaviour) whenever ATR isn't available.
      double trailDist = g_trail * Pt();
      if(InpUseATRTrail)
        {
         double atr = ATRValue();
         if(atr > 0.0)
            trailDist = atr * InpATRMultiplier;
        }

      if(InpTrailAfterBE && trailDist > 0.0)
        {
         double beLine = (ptype == POSITION_TYPE_BUY)
                         ? entry + g_beOffset * Pt()
                         : entry - g_beOffset * Pt();

         bool beOn = (ptype == POSITION_TYPE_BUY) ? (sl >= beLine - Pt())
                                                  : (sl > 0.0 && sl <= beLine + Pt());
         if(beOn)
           {
            if(ptype == POSITION_TYPE_BUY)
              {
               double nsl = NormalizePrice(bid - trailDist);
               if(nsl > sl + Pt())
                  trade.PositionModify(ticket, nsl, tp);
              }
            else
              {
               double nsl = NormalizePrice(ask + trailDist);
               if(sl <= 0.0 || nsl < sl - Pt())
                  trade.PositionModify(ticket, nsl, tp);
              }
           }
        }
     }
  }

// The EA never reads the chart's timeframe for a trading decision - every
// series is pulled explicitly (InpRangeTF, InpSignalTF, InpHTF). These two

// chart up with the signal timeframe so the drawings look right.
bool WarmSeries(ENUM_TIMEFRAMES tf, int bars)
  {
   MqlRates r[];
   ArraySetAsSeries(r, true);
   for(int attempt = 0; attempt < 5; attempt++)
     {
      int n = CopyRates(_Symbol, tf, 0, bars, r);
      if(n >= 5)
         return true;
      Sleep(200);   // give the terminal time to pull the series
     }
   return false;
  }

void PreloadAllSeries()
  {
   if(!InpPreloadHistory)
      return;

   bool okRange  = WarmSeries(InpRangeTF,  120);
   bool okSignal = WarmSeries(InpSignalTF, 200);
   bool okHTF    = WarmSeries(InpHTF,      MathMax(InpHTFEMA * 3, 120));

   Print("TWI Sniper | history  ", EnumToString(InpRangeTF),  (okRange  ? " ok" : " PENDING"),
         "   ",                    EnumToString(InpSignalTF), (okSignal ? " ok" : " PENDING"),
         "   ",                    EnumToString(InpHTF),      (okHTF    ? " ok" : " PENDING"));

   if(!okRange || !okSignal || !okHTF)
      Print("TWI Sniper | a series is still downloading - the EA will pick it up automatically on the next ticks.");
  }

void OnTick()
  {
   if(!TerminalInfoInteger(TERMINAL_TRADE_ALLOWED) || !MQLInfoInteger(MQL_TRADE_ALLOWED))
      return;

   RefreshStats(false);
   ManageOpen();

   datetime now = TimeCurrent();
   datetime st  = 0, en = 0;
   PickActiveWindow(now, st, en);

   if(st == 0)
     {
      if(sess.start != 0)
        {
         ReportSession(SessionName() + " close");
         CancelPendings();
         sess.setupLive = false;
         sess.start     = 0;
         sess.end       = 0;
        }
      Dashboard();
      return;
     }

   if(st != sess.start)
     {
      if(sess.start != 0)
         ReportSession(SessionName() + " close");
      ResetSession(st, en);
      RefreshStats(true);
      Log("Session open: " + SessionName() + "  "
          + TimeToString(st, TIME_MINUTES) + " - " + TimeToString(en, TIME_MINUTES));
     }

   // ---- Build the opening range FIRST.
   // Spread and trade caps must never prevent the range from being measured:
   // a momentarily wide spread during the range window used to kill the whole
   // session, because the range was never built and every later bar had
   // nothing to break out of.
   if(!sess.orReady)
     {
      if(BuildOpeningRange())
         DrawSetup();
      Dashboard();
      return;
     }

   bool tradingBlocked = false;

   if(IsFridayCloseWindow())
     {
      CancelPendings();
      tradingBlocked = true;
     }
   else
      if(DailyLimitsHit())
        {
         CancelPendings();
         tradingBlocked = true;
        }

   bool newSig = NewBar(InpSignalTF, lastSignalBar);

   if(!newSig)
     {
      if(!tradingBlocked && SpreadOK()
         && !InpConfirmCandle && InpEntryMode == ENTRY_SNIPER)
         TrySniper(false);
      Dashboard();
      return;
     }

   // ---- one evaluation per closed signal bar
   MqlRates r[];
   if(!CopySignal(r, 5))
     {
      Dashboard();
      return;
     }
   MqlRates closed = r[1];

   if(tradingBlocked)
     {
      dgCapDay++;
      Dashboard();
      return;
     }

   // Spread gates ENTRY only, and is counted so a spread-starved symbol is
   // visible in the session summary instead of failing silently.
   if(!SpreadOK())
     {
      dgSpread++;
      Dashboard();
      return;
     }

   CheckRearm(closed);

   if(!sess.breakSeen)
     {
      if(InpEntryMode == ENTRY_SWEEP)
         TrySweepEntry(closed);
      else
         TryBreakEntry(closed);
      DrawSetup();
     }
   else
      if(sess.setupLive && InpEntryMode == ENTRY_SNIPER)
        {
         TrySniper(true);
         DrawSetup();
        }

   Dashboard();
  }

void OnTradeTransaction(const MqlTradeTransaction &trans,
                        const MqlTradeRequest     &request,
                        const MqlTradeResult      &result)
  {
   if(trans.type == TRADE_TRANSACTION_DEAL_ADD)
      RefreshStats(true);
  }
